# Age modes and accessibility

## Kids mode

- Learn simple mantras and the **Hanuman Chalisa** verse by verse.
- Playful, calm visuals; no social features; parental controls.

## Seniors mode

- Large buttons and text, fewer screens.
- **Voice first:** start, pause and hear counts by voice.
- High-contrast option.

## Accessibility (baseline from P1, full audit in P3)

- Screen reader support (VoiceOver, TalkBack) for all counting modes.
- Dynamic text sizes, colour-contrast compliance.
- Audio feedback, and vibration where the browser supports it, so counting works without sight.
