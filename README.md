“Where silence learns to speak.”

## Current state

Beginning of Phase 0: Foundation. Solo project. English for now. The repository is public during setup, and the owner plans to make it private once the website is live. The blog will be a database-backed website built with Payload CMS, Next.js, Supabase and Netlify. See the [website design spec](website/docs/specs/2026-10-05-sagevani-website-design.md) and [D-004](docs/governance/decisions.md#d-004--website-platform-and-design). The owner has final approval of foundation revisions and publication. Public author byline: **Sagevani**.

Article drafts are written in the website's CMS and stay off the website until the owner publishes the approved version ([D-005](docs/governance/decisions.md#d-005--drafts-in-the-cms-admin-access-region-and-database-plan)). The assistant may draft without asking first; publication requires owner approval. Anything kept in this public repository remains readable here.

The folder structure is a working proposal. It does not establish official series, a publishing schedule, or a license.
