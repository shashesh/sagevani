# Foundation revision proposals

All items below are suggestions for owner review. None changes the transcribed v1 handbook.

| ID | Relevant section | Suggested addition | Reason |
| --- | --- | --- | --- |
| R-01 | Handbook governance | Add an owner approval record, effective version, and amendment history. | Clarifies when a working constitution changes. |
| R-02 | Charter / voice | Incorporate the confirmed novice-to-advanced audience, difficulty levels, and advanced-topic prior readings; approve specific labels separately. | Helps balance explanation and intimacy. |
| R-03 | Editorial integrity | Add claim-level verification status and exact evidence references to Source Cards. | Distinguishes located sources from checked evidence. |
| R-04 | AI use | Incorporate drafting without separate permission and owner approval before publication; decide disclosure separately. | Protects authorship while supporting collaboration. |
| R-05 | Publication workflow | Add an explicit owner approval step and publication record. | Makes final approval traceable. |
| R-06 | Corrections | Record date, affected claim, evidence, change, and whether a public correction note is needed. | Makes the existing corrections policy actionable. |
| R-07 | Vault | Incorporate same-workspace drafts excluded from the website; resolve confidentiality for other personal material separately. | Clarifies what unpublished means and what the website can expose. |
| R-08 | Source map | Track source access dates and verification status; distinguish research leads from checked sources. | Prevents inherited links from looking newly verified. |
| R-09 | Future languages | Treat each translation as an editorial version with source links and review. | Preserves philosophical nuance if multilingual work begins. |

Possible next version: v1.1, only after the owner approves a defined set of amendments. Version numbering is itself a proposal.
